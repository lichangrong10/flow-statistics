## 1 通用约定（全部接口适用）

### 1.1 基础
| 项 | 约定 |
|---|---|
| BaseURL | 开发 `/api/v1`（Vite proxy）· 生产 `/api/v1`（Nginx 反代） |
| 鉴权 | `Authorization: Bearer <token>`；令牌 2 小时有效 |
| 链路 | 请求头 `X-Trace-Id`（前端生成 UUID），响应体 `traceId` 回传，用于联合排查 |
| 幂等 | 所有写接口带 `Idempotency-Key`（前端按「用户动作 + 时间戳」生成，同一动作重试复用，TTL 10 分钟） |
| 编码 | JSON UTF-8；上传 `multipart/form-data`；导出为二进制流 |
| 超时 | 查询 10s / 写 15s / 上传 60s / 导出创建 15s / 下载 120s |

### 1.2 响应信封
```json
{ "code": 0, "message": "ok", "data": {}, "traceId": "8f3c2a1e9b7d4c60" }
```
- `code === 0` 视为成功；非 0 按 §5 映射。
- HTTP 状态与 `code` 双轨：`code` 表达业务语义，HTTP 表达传输语义（401/403 等仍按 HTTP 判断跳转）。

### 1.3 分页
所有列表 `data` 固定四字段：
```json
{ "items": [], "total": 0, "page": 1, "pageSize": 20 }
```
- 请求参数：`page`（默认 1）、`pageSize`（默认 20，上限 100）、`sort`（`field,asc|desc`，可选）。
- 前端**不做全量排序**，排序参数交后端。

### 1.4 数值与日期（硬约束）
| 类型 | 传输形态 | 示例 | 前端展示 |
|---|---|---|---|
| 金额 | **string**，2 位小数 | `"128600.00"` | `¥128,600.00` |
| 曝光量 / 人数 / 点击 | **string**，整数 | `"17125369"` | `17,125,369` |
| 比率 | **string**，4 位小数（0–1） | `"0.0115"` | `1.15%` |
| 计数（天数、条数） | number | `3` | 原样 |
| 日期 | `YYYY-MM-DD` | `"2026-11-23"` | 同 |
| 时间 | ISO8601 +08:00 | `"2026-11-23T10:30:00+08:00"` | `2026-11-23 10:30` |
| ID | number | `1024` | 不展示 |
| 单号 | string | `"DC20261123-1024"` | 等宽字体 |

> 金额与曝光量**禁止在传输层用浮点**；前端只在展示层格式化，计算一律用字符串/大整数工具，禁止 `parseFloat` 后直接参与财务汇总。

### 1.5 字段级错误（⚠️ 建议后端补充）
`1001 参数校验失败` 时 `data.errors` 返回字段级明细，供向导定位：
```json
{ "code": 1001, "message": "参数校验失败",
  "data": { "errors": [ { "field": "totalBudget", "message": "总预算不能小于日预算" } ] },
  "traceId": "..." }
```
- 导入类（3002）额外带 `row`：`{ "row": 37, "field": "impressions", "message": "曝光人数不应大于曝光量" }`。
- 前端若拿不到 `errors`，退化为全局提示 + 首个可疑字段聚焦（保持可用）。

## 5 错误码 → 前端行为

| code | HTTP | 含义 | 前端行为 |
|---|---|---|---|
| 0 | 200 | 成功 | 正常 |
| 1001 | 400 | 参数校验失败 | 有 `errors` 则字段级定位 + 滚动聚焦；无则 toast |
| 1002 | 401 | 未登录 / 令牌过期 | 清令牌 → 跳登录（带 `redirect`） |
| 1003 | 403 | 无权限 | toast「无权限」+ 页面级 403 兜底 |
| 1004 | 404 | 资源不存在 / 越权 | toast + 返回列表 |
| 2001 | 409 | 状态不允许该操作 | toast「状态已变化」+ **重新拉取详情** |
| 2002 | 409 | 计划名称重复 | 定位到名称字段 |
| 2003 | 409 | 预算超出项目余额 | 定位到总预算字段，附剩余可用金额 |
| 2004 | 409 | 厂商已被计划引用 | toast 建议改为停用 |
| 2005 | 409 | 厂商已停用 / 无效 | 厂商选择器标红并刷新候选 |
| 3001 | 400 | 导入文件格式错误 | 导入弹窗内联提示 |
| 3002 | 422 | 导入数据校验失败 | 展示前 50 条 + 下载错误行 |
| 3003 | 422 | 模拟参数超范围 | 参数表单字段级提示 |
| 4001 | 502 | 媒体接口失败 | toast「稍后重试或手工录入」 |
| 5000 | 500 | 服务内部错误 | toast 带 traceId，可复制 |

网络层：`ECONNABORTED/超时` → 「请求超时，请重试」；`Network Error` → 「网络异常，请检查内网连接」；GET 请求网络错误自动重试 1 次（仅一次）。

## 7 前端请求层行为规范（`src/api/request.ts`）

1. `baseURL = '/api/v1'`，`timeout = 10s`（上传/下载单独配置）。
2. 请求拦截：注入 `Authorization`、`X-Trace-Id`、写请求注入 `Idempotency-Key`；重复请求（同 method + url + params）用 `AbortController` 取消前一个。
3. 响应拦截：按 §5 映射；`code !== 0` 抛 `BizError(code, message, data)`；统一注入 `traceId`。
4. 401 处理：单飞（`isRefreshing` 标记）避免并发重复跳登录；跳转前保存 `redirect`。
5. 导出/上传：`responseType: 'blob'`，从 `Content-Disposition` 解析文件名。
6. 所有接口返回 `ApiResponse<T>`，封装函数只暴露 `data` 的 `T`；列表封装为 `PageResult<T>`。
