# 管理端合并说明（v1.0）

> 来源：`https://github.com/wwww-yl/adflow-admin-console`
> 合并方式：提取其 5 个管理页签与真实后端映射逻辑，套用用户端外壳与设计令牌，**不引入其独立工程、Mock 引擎、测试脚本与布局**。
> 日期：2026-11-23

## 1 功能范围

| 页签 | 能力 | 后端接口 |
|---|---|---|
| 管理员账号 | 查询、编辑名称、启停、重置密码；账号由后端统一发放，不提供新增 | `/users`、`PATCH /users/{id}`、`/users/{id}/reset-password` |
| 厂商管理 | 查询、新增、编辑、启停、删除（被计划引用时仅能停用） | `/vendors` CRUD |
| 字典配置 | 渠道字典可编辑（名称、启停、默认出价）；年龄段与指标口径已移除 | `/channels`（GET/PUT） |
| 操作日志 | 关键词/对象类型/操作人/日期检索、展开详情、CSV 导出 | `/logs`、`/users` |

## 2 登录与权限

- 平台只保留 **管理员登录**（`/admin/login`），不再提供普通用户登录页；旧 `/login` 地址自动跳转。
- 登录时校验 `role=admin`，非管理员账号拒绝登录并清理会话。
- 管理员登录成功默认进入 **/admin（系统管理）**，侧栏显示「系统管理」菜单，同时可访问全部业务页面。
- 所有受保护路由都要求管理员会话；不再使用 `adminOnly` / 403 页面做角色隔离。
- 账号管理页只展示后端发放的管理员账号，不提供新增入口；创建账号逻辑已移除。

## 3 目录结构

```
src/admin/                 管理端自包含模块（不依赖用户端 DTO）
├── backend.ts             后端字段映射（用户/厂商/日志/模拟参数/渠道/字典）
├── system.ts / campaign.ts 业务接口封装
├── request.ts             复用用户端 axios 实例与令牌
├── types.ts / constants.ts / domain.ts / format.ts / validate.ts / error.ts / download.ts
├── engine.ts              模拟曲线预览算法（仅预览，不写库）
├── config.ts              固定真实后端模式
└── components/            BaseChart / EmptyState / StatusTag（管理端样式）
src/views/admin/
├── AdminView.vue          系统管理外壳（PageHeader + 四页签）
└── tabs/                  UsersTab / VendorsTab / DictTab / LogsTab
```

## 4 与用户端的融合

- **外壳**：复用 `DefaultLayout`（侧栏、顶栏、管理员账号菜单）、`PageHeader`、设计令牌与 Element Plus 主题，不再保留管理端独立布局。
- **路由**：`/admin` 挂在现有布局下，所有受保护路由统一要求管理员会话，守卫在 `src/router/index.ts`。
- **登录**：删除 `src/views/login/index.vue`，只保留 `AdminLoginView.vue`，登录后进入 `/admin`。
- **菜单**：`DefaultLayout` 中管理员动态追加「系统管理」。
- **依赖隔离**：管理端类型与工具在 `src/admin/` 内自包含，避免与用户端 DTO 冲突；共用的只有请求层与 UI 组件。

## 5 已知限制

| 项 | 说明 |
|---|---|
| 渠道表前置依赖 | 后端计划创建校验「投放渠道存在且启用」；后端重置后需先播种渠道（`scripts/seed-real.py` 已包含） |
| 常用方案 | 存浏览器 localStorage，换浏览器不同步 |
| 调节记录 | 由 `/logs` 中 `mock_*` 动作反推，非独立表 |
| PDF 报表 | 后端 pdfkit 缺字体，报表中心已移除 PDF 选项 |
| 报表删除 | 后端无 `DELETE /reports/:id`，测试任务无法清理 |
