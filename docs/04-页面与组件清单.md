# 页面与组件清单（v0.1 · 开发基线）

> 注：本清单为原始方案库存档。当前实现已收敛为管理员单一入口，`/login` 普通用户登录页已移除，账号管理仅维护管理员账号；以 README 与 10-管理端合并说明为准。

> 说明：文中「Mock 策略」为契约先行阶段的实施方案，现已移除；当前实现与接口以 `docs/07-真实接口联调记录.md` 为准。


> 依据：《前端技术方案》V1.3 第 3/4/6/8 章 + 《接口契约》v0.1
> 本文档回答三件事：**页面有哪些、每页怎么构成、组件怎么定接口**。开工前评审通过即冻结为 v1.0。

**菜单顺序**：工作台 · 投放计划 · 数据回收 · 数据看板 · 报表中心 · 管理。
`/admin` 无权限时：普通用户菜单不显示，直访跳 `/403`（不弹 toast）。

**布局**：左侧 200px 导航（可折叠至 64px）+ 顶栏 56px（项目切换 / 数据更新时间 / 用户菜单 / 退出）+ 内容区（左右留白 24，卡片内边距 20）。

### 公共页
- `/403`：说明所需角色 + 「返回工作台」；`404`：路径提示 + 返回。
- 会话过期：弹窗提示「登录已过期」→ 10s 倒计时或点击 → 跳 `/login?redirect=…`。
- 全局错误兜底：`app.config.errorHandler` + 错误上报（`traceId` 可复制）。

## 3 页面状态矩阵（每页必做，验收抽查）

| 场景 | 表现 | 恢复 |
|---|---|---|
| 首次加载 | 骨架屏，保持布局不跳动 | 加载完成替换 |

| 模拟数据 | 黄色提示条「当前为模拟数据」 | — |

**封装规范（方案 §6.3/6.4 落地）**
- `BaseChart`：统一注册主题（色序取自令牌），`ResizeObserver` 自适应，隐藏时 `dispose`；空数据渲染 `EmptyState`；千分位与单位统一处理；不在业务页硬编码颜色。
- `DataTable`：列配置对象 `{prop,label,width,align,formatter,sortable,fixed}`；分页/排序/筛选交后端；>200 行启用虚拟滚动；固定首列与操作列；空态 + 错误态 + 加载态内置。
- `v-perm`：`mounted` 时校验 `hasPerm`，无权限移除节点；**仅控制可见性**，不做安全边界。
