# 投流统计平台

> 2026 年太仓分公司全域融数智能投放服务 · 投流统计平台
> 范围：**只做前端、只做用户端**（管理端与后端不在本期）
> 当前阶段：**用户端 8 个页面已接真实内网后端**（192.168.9.224:3000）

## 一、项目说明

把「投放动作」与「投放结果」结构化为可查询、可核验、可导出的数据资产。平台不向媒体真实下单，曝光 / 点击 / 消耗由后端按模拟参数生成并支持调节，用于流程验证、内部演练与验收演示。

- 技术栈：Vue 3.5 + TypeScript 5.4 + Vite 5.2 + VueRouter 4.6 + Pinia 2.1 + Element Plus 2.14 + ECharts 5.5 + Day.js 1.11 + SheetJS（按需加载）
- 已实现页面：登录、工作台、投放计划、发布投流向导、投放详情、数据回收、数据看板、报表中心（+ 403/404）
- 数据来源：内网后端 `http://192.168.9.224:3000/api/v1`，通过 Vite 代理同源访问；仓库内不含 Mock 数据层

## 二、环境与启动

### 环境要求

- Node.js 18+、pnpm 8+
- 后端 `http://192.168.9.224:3000` 可访问（代理已在 `vite.config.ts` 配置好）

### 命令

```bash
pnpm install      # 安装依赖
pnpm dev          # 开发服务，默认 http://localhost:5273
pnpm build        # 生产构建到 dist/
pnpm preview      # 本地预览 dist/
pnpm type-check   # vue-tsc 严格类型检查
```

启动日志会打印两个地址（监听 `0.0.0.0`）：

```

Network: http://192.168.9.223:5273/   （局域网内可访问）
```

## 六、接口层与代理

- 所有页面只调用 `src/api/*`，内部统一走 `request()`（axios，`baseURL=/api/v1`）。
- 开发环境代理：`vite.config.ts` 的 `server.proxy['/api']` → `http://192.168.9.224:3000`。
- 生产环境：Nginx 反代 `/api/`，见方案 §11.2；`.env.production` 只保留 `VITE_API_BASE`。
- 字段映射集中在 `src/api/real.ts`，后端字段变化只改这一层。
- 详情页「生成模拟数据」弹窗的曲线预览使用 `src/utils/preview-generator.ts`，仅本地预览，不写库；实际生成由后端 `/mock/generate` 完成。

## 七、联调状态

**已经跑通（真实后端）**：登录 / 工作台 6 卡与趋势 / 计划列表筛选分页 / 计划详情 5 页签 / 手工录入保存 / 报表创建与 xlsx 下载 / 草稿创建与删除 / 状态流转（提交、审核、发布、暂停、恢复、结束、结案）。

**后端行为差异（前端已适配，建议后端知悉）**：

| 项 | 现状 | 前端处理 |
|---|---|---|
| 写接口空 body | 必须带 `{}`，否则 400 | 请求层自动补空 JSON |
| 人群维度 | dimRatio 必须是 `{地域:{名称:比例}}` 映射；数组格式会导致生成 500 | 适配层转换 |
| 维度周期 | 人群分布按计划全周期聚合，不随 `from/to` 过滤 | 看板标注「计划全周期累计」 |
| 汇总口径 | 周期内曝光 ÷ 计划总目标（目标未按周期折算） | 按后端返回展示，KPI 加口径提示 |
| 模拟生成 | 不清理区间外旧数据 | 演示数据统一按完整排期生成 |
| 报表 | 仅支持 `campaign` / `daily` 两种，无文件大小、文件名为 UUID | UI 收敛为「结案报告 / 数据明细」，展示友好文件名 |
| 导入 | 返回 422 + `details[{row,code,message}]` | 错误行映射展示 |
| 字典 / 令牌续期 | 无 `/dicts`、无 `/auth/refresh` | 内置字典、401 跳登录 |

**仍待确认**：人群维度按日期过滤、汇总目标折算、报表 PDF 与友好命名、字典接口。
